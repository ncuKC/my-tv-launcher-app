# 1.0.0 — 14 ноября 2026

Первый выпуск линии 1.0 на основе 0.3.6. Код функций не меняется; обновлены номер версии и документация. Пакет ru.mytv.launcher и постоянный ключ подписи сохранены.

## Возможности

- Домашний экран без встроенной рекламы и рекомендаций, часы и управление пультом.
- Избранное с перемещением плиток, сохранением по OK и отменой по Назад; скрытие и восстановление приложений.
- Размеры плиток, число колонок, сохранение настроек и восстановление фокуса.
- RAM и CPU с различием нагрузки приставки и приложения.
- Пейзажи и перемещающиеся часы, собственное окно настроек заставки, раздельный предпросмотр с загрузкой и ошибками.
- Живые подборки Commons/Openverse, ограниченная история против повторов без дискового кэша фото; три прежних Unsplash только в резерве. Отдельных переключателей источников и динамического Unsplash API нет.
- Настраиваемая подготовка после перезагрузки без пропуска через OK/Назад.
- Автопроверка обновления примерно раз в 20 минут при открытом лаунчере, значок ↑; ручная загрузка с прогрессом, проверкой пакета, версии и подписи.
- Локальная диагностика с копированием.

## Установка

Скачайте My-TV.apk из Assets и откройте на приставке, разрешив установку приложению-источнику при запросе Android. Source code не является установщиком. Релизы с постоянной подписью обновляйте поверх, не удаляя приложение.

[Полная инструкция и управление](https://github.com/ncuKC/my-tv-launcher-app/blob/v1.0.0/README.md), включая назначение домашнего экрана через TV Box Tools. Возможность смены HOME зависит от прошивки; инструмент сторонний.

## Совместимость

Есть положительная обратная связь на Xiaomi TV Box S / Mi Box S 3rd Gen. Полный протокол испытаний и точная версия прошивки не зафиксированы; другие модели не заявлены как проверенные. HOME, сон, системная заставка и установщик зависят от прошивки. Фото зависят от внешних API и сети.

К APK прилагается SHA256SUMS.txt. Release публикуется только после сборки и проверки подписи в Actions. Фотографии интерфейса в этот коммит не включены.
