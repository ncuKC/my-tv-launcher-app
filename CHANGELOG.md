# 0.3.3

- Удержание OK открывает меню плитки: избранное, перемещение раньше/позже и скрытие.
- Порядок избранного сохраняется. Старое избранное импортируется из прежних настроек без удаления. Начальное выделение учитывает новый порядок.
- Скрытые приложения исключаются из обеих сеток, но не удаляются с приставки. Вернуть их можно в настройках; избранное у скрытого приложения сохраняется.
- Размер плиток: компактные, обычные, крупные. Колонки: авто, 3, 4, 5, 6. Выбор сохраняется.
- Раздел «О приложении и диагностика»: версия, устройство, последняя ручная проверка, результат и ошибка, параметры интерфейса и заставки, копирование текста. Данные локальные, телеметрии нет.
- Обработчик успешного обновления из лаунчера пытается открыть новую версию. Совместимость со старым именем callback-компонента сохранена через activity-alias. При отказе запуска есть понятное сообщение. Установка APK извне не вызывает этот обработчик.
- Прогресс обновлений, настройки заставки и экран запуска из 0.3.2 сохранены. Кэширование пейзажей не добавлялось. Подпись и пакет прежние, versionCode 303.

Автоматическая публикация выполняется после сборки и проверки подписи. UI, установка и возврат на конкретной прошивке требуют проверки.
