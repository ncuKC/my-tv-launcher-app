# 0.3.6

- Вместо цикла из трёх фото добавлены живые интернет-подборки Wikimedia Commons и Openverse. Подборки запрашиваются при запуске и пополняются по мере просмотра; темы и страницы меняются между обращениями и запусками. Наличие новых подходящих результатов зависит от API и сети.
- Два каталога автоматически чередуются. Openverse ищет фото вне Wikimedia, чтобы второй путь не сводился к тому же каталогу. Отдельных переключателей источников в этой версии нет.
- Отбираются горизонтальные изображения исходным размером не меньше 1280×720, с соотношением сторон от 1.3 до 3.0. После загрузки формат и размеры проверяются повторно. Поиск тематический, не ручная модерация: точное содержание каждого результата не гарантируется.
- На первом этапе используются только CC0 / Public Domain. Название, автор и лицензия берутся из ответа каталога. Unsplash остаётся явно обозначенным резервом из прежних трёх фото; новые подборки Unsplash API не подключены.
- При ошибке каталога или отдельных фото пробуется другой путь. После HTTP 429 выдерживается пауза, подборки ограничены 20 записями. Общий бюджет поиска около 30 секунд плюс завершение текущего сетевого чтения.
- Сохраняются только идентификаторы/URL и хеши последних показанных снимков (до 256 записей), позиция поиска и срок паузы каталогов. Фотографии и подборки на диск не записываются; HTTP-кэш отключён. Память подборок освобождается при закрытии заставки. Защита от повторов ограничена историей, а не вечная.
- В предпросмотре видны поиск и ошибки; в автоматической заставке сохраняется предыдущий снимок, если он есть, иначе часы. Последний источник, название, лицензия и ссылка на страницу записываются в локальную диагностику.
- Настройки, перемещение избранного, пакет и подпись сохранены.

Нужны успешная сборка и проверка новых API на Xiaomi. Запись коммита не является подтверждением готовности APK.
