# Техническая информация

[На страницу приложения](README.md)

## Пакет и обновления

Релиз: ru.mytv.launcher. Debug: ru.mytv.launcher.test — отдельное приложение без самообновления. С 0.3.0 релизы используют постоянную подпись; обновление поверх сохраняет настройки.

Наличие релиза проверяется примерно раз в 20 минут при открытом лаунчере. Ручное обновление скачивает APK и проверяет пакет, версию и сертификат перед установкой. Системное разрешение установки и подтверждение могут потребоваться.

## Показатели нагрузки

RAM и CPU обновляются примерно раз в 5 секунд при открытом лаунчере. Общая нагрузка CPU доступна, если её чтение разрешено прошивкой; иначе явно показывается CPU приложения.

## Интернет-заставка

Каталоги: Wikimedia Commons и Openverse. Для новых подборок используются фото с метаданными CC0 / Public Domain. Отбираются горизонтальные изображения исходным размером от 1280×720, с соотношением сторон 1.3–3.0; декодирование может уменьшать разрешение для ограничения памяти. Поиск тематический, без ручной модерации каждого снимка.

Три фиксированных снимка Unsplash остаются аварийным резервом. Динамический Unsplash API и отдельные переключатели источников не подключены.

Фотографии не кэшируются на диске. Подборки находятся в памяти. Для уменьшения повторов сохраняются URL и хеши показанных фото, до 256 записей, обычно по две на снимок, позиция поиска и сроки пауз каталогов. После HTTP 429 каталог ставится на паузу. Доступность выдачи зависит от сети и API; офлайн-фотоколлекции нет.

Системная DreamService доступна в совместимых прошивках; запуск заставки в других приложениях контролирует Android. Назначение HOME через TV Box Tools также зависит от прошивки.

## Данные и сеть

Настройки, история фото и краткая диагностика локальные; отчёт автоматически не отправляется. Запросы идут в GitHub для обновлений, Commons/Openverse для каталогов, на серверы фотографий из ответов и в Unsplash для резерва. Внешние сервисы получают обычные сетевые данные, включая IP-адрес.

## Сборка и выпуск

JDK 17, Gradle 8.9, Android SDK 35. [Workflow](https://github.com/ncuKC/my-tv-launcher-app/actions/workflows/build.yml).

Обычный push в main собирает debug APK. Push с сообщением, начинающимся на [release], запускает выпуск; альтернатива — ручной workflow с publish. Собираются debug и подписанный release, проверяется подпись, формируются SHA256SUMS.txt и APK-check.txt. После успешных шагов создаётся Release с My-TV.apk и SHA256SUMS.txt; описание берётся из CHANGELOG.md. Артефакты Actions хранятся 3 дня, это не срок хранения Release.

Перед выпуском повышайте versionName и versionCode в app/build.gradle. Формула: major*10000 + minor*100 + patch, minor/patch 0–99; 1.0.0 → 10000. Не переиспользуйте теги; пакет и ключ не меняйте.

Repository secrets: KEYSTORE_BASE64, KEYSTORE_PASSWORD. PKCS12, alias launcher, пароль ключа совпадает с паролем хранилища. Не публикуйте ключ и пароль в коде, issues или логах. Храните отдельную защищённую резервную копию: замена ключа не позволит обычное обновление установленных релизов.
